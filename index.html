📖 Инструкция: как получить Client ID
  1. Перейди на dev.twitch.tv/console
  2. Нажми Register Your Application
  3. Имя: любое (например, TopBot-Roulette)
  4. OAuth Redirect URLs: —
  5. Category: Website Integration
  6. Скопируй Client ID и вставь в поле выше
  7. Нажми «Войти через Twitch» и разреши доступ
